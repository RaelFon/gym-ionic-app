**Prerequisites for Running an Ionic Project**

To set up and run an Ionic project on your machine, you need to have the following dependencies installed:

### 1. **Node.js and npm**
Ionic requires Node.js to function properly, as it utilizes npm (Node Package Manager) for installing dependencies and managing packages.

- **Download and install Node.js**: You can download the latest stable version of Node.js from the official website:
  - [https://nodejs.org/](https://nodejs.org/)
- **Verify installation**:
  - To check if Node.js is installed, run the following command in your terminal:
    ```sh
    node -v
    ```
  - To check if npm is installed, run:
    ```sh
    npm -v
    ```

### 2. **Ionic CLI**
The Ionic CLI (Command Line Interface) is necessary for creating, building, and running Ionic applications.

- **Install Ionic CLI globally using npm**:
  ```sh
  npm install -g @ionic/cli
  ```
- **Verify installation**:
  ```sh
  ionic -v
